# FitFeast Nutrition

A full-stack web application for personalized nutrition and wellness tracking.

## Features

- User registration and login
- BMI and calorie tracking
- Meal logging and history
- Personalized meal plans
- Progress tracking
- Nutrition reports
- Responsive UI

## Tech Stack

- HTML, CSS, JavaScript
- Node.js, Express.js
- PostgreSQL
- Chart.js
- JWT, bcrypt

## Run Locally

git clone https://github.com/Hamsika-rao/FitFeastNutrition.git

cd FitFeastNutrition

nodemon installation

npm run dev


Create a `.env` file with your PostgreSQL and JWT configuration.

Open:

http://localhost:3000
